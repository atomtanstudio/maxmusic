Decisions that shaped the build
Round 1's verdict, in one line: we published our own plumbing as product UI. All five judges found the build the same way — a LAN address in the sidebar, endpoint paths under buttons, model quantization strings, byte counts, even a spec section number. None of them saw the code. Diagnostics now live in Settings and in errors that only appear when something is actually wrong.
The brief caused it. The contract told builders to surface backend detail honestly, and they made it permanent furniture. “Honest” means never faking success — not publishing the machine to the user. The contract has been rewritten.
Cut: guidance and step sliders. Both read from server environment variables, not the request body. A slider for either would move nothing — so they appear in Settings as read-only server values instead.
Cut: auto-lyrics toggle. lyrics_optimizer throws outright in ComfyUI mode. Simple mode calls the lyrics endpoint first and shows you what it wrote.
Brand sampled, not guessed. The ramp comes from the logo's own pixels, left to right: #00C0E0 #0090F0 #7060F0 #B040F0 #F04060 #E0A040.
Suno is the floor, not the template. A screen that reads as a Suno reskin fails even if it is well made. The judging asks which looks like a shipped product — the aim is to win it.
The old app is untouched. It keeps running on :3010 and is also the backend this build proxies to. The redesign serves from :3020.
Round 1 complete — 0 of 5, every gap named and recorded. Round 2 in flight: chrome de-plumbed, five channels rebuilding against their own verdict, then a fresh blind panel that has never seen either build. The loop runs until the screens win or you stop it.
